MiniConda Navigator v2.5 - Program Description
🏆 WHAT IS IT?
A Graphical Interface for Conda/Python Management - A desktop application that replaces using the console/terminal for managing Python environments.

🎯 KEY FEATURES
1. 🐍 CONDA ENVIRONMENT MANAGEMENT
Browse all Conda environments on your computer

Create new environments (with Python version selection)

Delete environments (with protection for "base" environment)

Quick switching between environments

View active environment (marked with a star ★)

2. 📦 PACKAGE MANAGEMENT
List packages in the current environment

Install packages (via pip or conda)

Uninstall packages

Search for packages in repositories

Update pip and conda

3. 📝 PYTHON SCRIPT MANAGEMENT
Browser for .py files in selected folder

Create new scripts with template

Run scripts in selected environment

Stop/restart running scripts

View output in dedicated terminal

Search for all .py files in subfolders

4. 💻 TERMINAL AND COMMANDS
Environment terminal - opens CMD with active environment

Execute any commands conda/pip

Quick commands (pip list, conda list, install, etc.)

Real-time output preview of commands

History of results from executed commands

5. 🔧 ADVANCED FEATURES
Export/import environments to/from YAML files

Clear conda cache

Manage pip repositories

Set default script folder

Open folders in Windows Explorer

🌍 MULTILINGUAL SUPPORT
6 built-in languages: EN, PL, DE, ZH (Chinese), HU (Hungarian), LT (Lithuanian)

Dynamic language switching without restart

Remember selected language

Easy addition of new languages (via JSON files)

🎨 INTERFACE
Modern design with panel layout

Color scheme following UX principles

Status bar with information

Icons and emojis for better readability

Responsive layout (resizable window)

⚡ TECHNOLOGIES
Python 3.x with Tkinter (native GUI)

Compilation to .exe (PyInstaller)

Conda integration (uses Windows console)

Multithreading (doesn't block UI during command execution)

JSON configuration (saving settings)

🎯 WHO IS THIS PROGRAM FOR?
Python beginners - don't need to learn console commands

Data Scientists - quick environment management for different projects

Teachers/educators - easy demonstration of Python environments

Developers - quick testing of scripts in different environments

Administrators - managing environments on multiple computers

🔧 EXAMPLE USE CASES
New ML project: Creating environment with TensorFlow and pandas

Script testing: Quick run in isolated environment

System cleanup: Removing unused environments and packages

Project migration: Exporting environment to YAML file

Demo/presentation: Showing different Python versions without restart

🔄 WORKFLOW
text
Select environment → Install packages → Create/run script → Analyze results
All in one window without opening the console! 🚀
